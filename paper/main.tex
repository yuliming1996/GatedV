\begin{abstract}

Standard attention forms query (Q), key (K), and value (V) matrices through learned linear projections of input hidden states. Architectures such as GAU and Mega incorporate nonlinear transformations into attention. In this paper, we propose GatedV, a simple attention variant that applies SiLU only to V before aggregation without introducing additional trainable parameters. We evaluate GatedV against a standard decoder-only Transformer using matched parameter counts, paired initializations, and equal training-token budgets. At 2.33M parameters, GatedV reduces mean held-out perplexity from 59.1 to 57.9 (2.0\%), with improvements across all five paired seeds. At 26.16M parameters, following an equal-budget learning-rate search, mean held-out perplexity falls from 20.2 to 19.7 (2.4\%), with improvements across all three paired seeds. Small-model ablations show that the tested affine rescaling of values does not fully reproduce GatedV's gains. A short interleaved benchmark on NVIDIA DGX Spark measures approximately 0.7\% higher full-context forward latency for the larger model, based on synchronized wall-clock timings. These findings suggest that value-only self-gating can improve language modeling performance without increasing parameter count or redesigning the attention-weighting mechanism.
\end{abstract}

\section{Introduction}

Standard Transformer blocks combine self-attention with position-wise feed-forward networks~\citep{transformer}. The feed-forward sublayer applies nonlinear transformations to individual token representations, whereas attention mixes information across tokens. Within attention, queries (Q) and keys (K) determine the mixing weights, and values (V) provide the representations to be combined. These three branches are usually formed by linear projections, despite their different roles. An additional nonlinearity on queries or keys changes the weighting calculation; on values, it changes what enters the weighted sum. Moreover, applying a nonlinearity before aggregation is generally not equivalent to applying it afterward.

Nonlinear value representations are already used in several attention architectures. Mega applies SiLU to projected values in a block that also uses moving-average features and additional gates~\citep{mega}. HYLA introduces nonlinear value computation without additional parameters, together with normalization across attention heads~\citep{hypernetwork}. Neural Attention instead replaces the linear Q/K/V projections with multilayer perceptrons~\citep{neuralattention}. Gated Attention compares gates at several locations, including the value projection, with its main results using a learned sigmoid gate after scaled dot-product attention~\citep{gatedattention}. GLU Attention introduces separate content and gate projections and reduces the aggregated value width to match the combined value/output projection-weight count~\citep{gluattention}. These approaches differ in both the source of the nonlinearity and the computation surrounding it.

In this paper, we ask whether a nonlinear value transform improves a standard Transformer when the other components are left unchanged. A parameter-free elementwise activation allows the original projection dimensions and block configuration to be retained, while altering only the operation applied to the projected values.
We call this variant GatedV (self-gated values). It applies SiLU to the usual value projection $V$ before attention aggregation:
\[
    \widetilde V=\silu(V)=V\odot\sigma(V),
\]
where $\sigma$ is the elementwise sigmoid function. The same projected values supply both the content and its gate, so no separate learned gate projection is needed. The query/key projections, softmax weighting rule, and remaining Transformer components are retained. GatedV therefore has exactly the same number of trainable parameters as the baseline, without adjusting the depth or width of either model.

We train baseline and GatedV decoder-only language models from scratch on FineWeb-Edu~\citep{fineweb}, at 2.33M and 26.16M parameters and with equal training-token budgets within each scale. GatedV reduces mean held-out perplexity by 2.0\% and 2.4\%, respectively, with improvements in every paired confirmation run. Additional experiments examine activation placement, learning-rate sensitivity, initial value statistics, and computational cost. Whether these improvements persist at larger scales, on other corpora, or on tasks beyond next-token prediction remains to be tested.
Code, experiment recipes, and recorded results are available at \url{https://github.com/yuliming1996/GatedV}.


\section{Background and model formulation}
\label{sec:background}

\subsection{Transformer backbone}
\label{sec:backbone}
Our baseline is a decoder-only Transformer with causal multihead attention~\citep{transformer,gpt}. Each block uses RMSNorm before its attention and feed-forward sublayers~\citep{rmsnorm}, rotary positional embeddings for queries and keys~\citep{rope}, and a SwiGLU feed-forward transformation~\citep{swiglu}.

Let $X\in\mathbb{R}^{T\times d}$ denote the hidden states entering a block, where $T$ is the sequence length and $d$ is the model width. We omit the batch dimension and use row-vector notation. The attention sublayer first computes
\begin{equation}
 U=\rms_{\gamma_a}(X),\qquad
 Q=UW_Q,\quad K=UW_K,\quad V=UW_V,
 \label{eq:projections}
\end{equation}
where $W_Q,W_K,W_V\in\mathbb{R}^{d\times d}$. RMSNorm acts on each token independently:
\begin{equation}
 \rms_\gamma(x)=\gamma\odot
 \frac{x}{\sqrt{d^{-1}\sum_{j=1}^{d}x_j^2+\epsilon}},
 \qquad \epsilon=10^{-6}.
 \label{eq:rmsnorm}
\end{equation}
The projected tensors are split into $H$ heads of width $d_h=d/H$. For head $h$, let $\widehat Q_h=\operatorname{RoPE}(Q_h)$ and $\widehat K_h=\operatorname{RoPE}(K_h)$. We use a rotary base of 10,000. The attention weights and output are
\begin{equation}
 A_h=\softmax\!\left(
 \frac{\widehat Q_h\widehat K_h^\top}{\sqrt{d_h}}+M
 \right),\qquad
 O=\operatorname{Concat}_{h=1}^{H}(A_hV_h),
 \label{eq:attention}
\end{equation}
where $M_{ij}=0$ for $j\leq i$ and $M_{ij}=-\infty$ otherwise. Softmax is applied across the key positions in each row. Values enter this aggregation linearly for fixed $A_h$, although attention as a function of $X$ is nonlinear because the weights themselves depend on the input.

The block then applies the two residual updates
\begin{align}
 X'&=X+OW_O,\\
 Z&=\rms_{\gamma_f}(X'),\\
 X_{\mathrm{next}}&=X'+
 \big[\silu(ZW_1)\odot(ZW_2)\big]W_3,
 \label{eq:block}
\end{align}
where $W_O\in\mathbb{R}^{d\times d}$, $W_1,W_2\in\mathbb{R}^{d\times d_{\mathrm{ff}}}$, and $W_3\in\mathbb{R}^{d_{\mathrm{ff}}\times d}$. The SiLU activation is $\silu(z)=z\sigma(z)$, with $\sigma(z)=(1+e^{-z})^{-1}$~\citep{silu,swish}; both the activation and $\odot$ act elementwise. After $L$ blocks, a final RMSNorm precedes the vocabulary readout, whose weights are tied to the input embedding. All learned linear maps are bias-free. Dropout and additional headwise query/key normalization are disabled.

\subsection{Nonlinear projections and attention gates}
\label{sec:related}
Nonlinear features can be introduced at several stages of attention, beginning with the projections that construct Q, K, and V. Neural Attention replaces these linear maps with two-layer networks containing LayerNorm and ReLU~\citep{neuralattention}. This increases the projection parameter count. Its ReLU ablation retains the expanded key/value projections and LayerNorm, testing the activation within the modified network rather than comparing with a parameter-matched standard Transformer.

Nonlinear values also appear in architectures that redesign the attention block more broadly. The Gated Attention Unit (GAU) combines nonlinear values and shared query/key features with squared-ReLU attention and multiplicative gating in a unified attention and feed-forward layer~\citep{gau}. Mega builds on this construction, deriving shared query/key features from exponential moving averages and adding reset and update gates~\citep{mega}. Its value branch applies SiLU directly to the projected inputs before aggregation. This provides a direct precedent for value-side SiLU, although the surrounding computation differs from conventional multihead attention.

GLU Attention retains softmax aggregation and uses two independently projected branches, $\widetilde V=(UW_C)\odot\silu(UW_G)$~\citep{gluattention}. For model width $d$, it sets the combined value width across heads to $m=2d/3$. Ignoring biases, the two $d\times m$ input projections and the $m\times d$ output projection then contain $3dm=2d^2$ weights, matching the standard value and output projections. Thus its parameter matching involves narrower values and a separate learned gate. GatedV instead preserves the original value width and projection matrices, applying SiLU directly to a single projected value tensor.

Other formulations make the nonlinear transformation depend on how values are combined. HYLA applies ReLU to an attention-weighted combination of value features across heads for each query--key pair. It introduces no additional parameters and uses RMS normalization across heads instead of key-wise softmax~\citep{hypernetwork}. LASER retains softmax weights but combines an exponential value transform with a logarithm after aggregation, giving $\log\!\big(A_h\exp(V_h)\big)$~\citep{laser}. These operations are not generally equivalent to applying an activation independently to each projected value and then taking the usual weighted sum.

Gate placement has also been studied while retaining softmax attention. Gated Attention compares learned gates on Q/K/V and at the attention output, with its main configuration using a head-specific sigmoid gate after scaled dot-product attention~\citep{gatedattention}. \textbf{Its G2 gate uses a separate input projection to compute a sigmoid gate on the values before aggregation.} It also evaluates SiLU applied directly to the attention output without additional parameters \textbf{(their Table~3, row~6)}. Two distinctions are relevant here: whether the gate uses a separate learned projection, and whether it acts before or after aggregation. We examine self-gating of the projected values before aggregation, retaining the original projections and the softmax weighting rule.

\subsection{GatedV}
\label{sec:model}
GatedV replaces the projected values in Equation~\ref{eq:projections} with
\begin{equation}
 \widetilde V=\phi(V)=V\odot\sigma(V),
 \qquad \phi=\silu.
 \label{eq:selfgate}
\end{equation}

\begin{figure}[t]
\centering
\includegraphics[width=\linewidth]{figures/architecture_gatedv.pdf}
\caption{Transformer block and GatedV value transformation. The baseline aggregates the projected values $V$, whereas GatedV applies $\silu(V)$ before aggregation. The value box shows the two alternatives; each model uses one.}
\label{fig:architecture}
\end{figure}

The Q/K/V projections are implemented as one fused linear map. After splitting its output into three tensors, we apply $\phi$ to $V$ before reshaping into heads. The per-head comparison is therefore
\begin{equation}
 Y_h^{\mathrm{base}}=A_hV_h,\qquad
 Y_h^{\text{GatedV}}=A_h\phi(V_h).
 \label{eq:vonly}
\end{equation}
Figure~\ref{fig:architecture} shows where the value activation is applied.

The gate is determined by the same projected value that it multiplies. It requires no separate projection such as $W_G$ in $(UW_V)\odot\sigma(UW_G)$, the two-projection form of a gated linear unit~\citep{glu}. Placement also matters: in general,
\begin{equation}
 A_h\phi(V_h)\neq\phi(A_hV_h).
 \label{eq:placement}
\end{equation}
The left-hand side transforms each source token's value before mixing it with other values; the right-hand side transforms the resulting mixture.

For a fixed normalized input $U$ and fixed query/key projection weights, GatedV leaves $A_h$ unchanged. No trainable tensors are added or resized. The depth, hidden widths, head structure, normalization, positional encoding, and feed-forward blocks remain as defined above, so paired baseline and GatedV models can start from identical weights. The activation adds $O(Td)$ elementwise work per block. 

For the activation-placement experiments, we also apply $\phi$ to queries alone or to all three of Q, K, and V. Query and key activations are applied before RoPE. These variants retain the original depth and projection dimensions.

Small-model ablations compare activation placement and learning rates using three paired seeds and 32,768 updates per run (Table~\ref{tab:ablations}). We also test whether fixed adjustments to the initial value statistics can reproduce GatedV's gain. Affine match rescales and shifts the baseline values to match the mean and variance of SiLU-transformed values; Moment-matched SiLU applies the reverse adjustment to SiLU-transformed values, matching the original value statistics. For each seed and layer, we estimate $(\mu_V,\sigma_V)$ and $(\mu_\phi,\sigma_\phi)$ from 128 training windows at baseline initialization and define
\begin{align}
 V_{\mathrm{aff}}&=\frac{\sigma_\phi}{\sigma_V}(V-\mu_V)+\mu_\phi,\\
 V_{\mathrm{mm}}&=\frac{\sigma_V}{\sigma_\phi}\big(\phi(V)-\mu_\phi\big)+\mu_V.
 \label{eq:controls}
\end{align}
The coefficients remain fixed throughout training. At peak learning rates 0.0024 and 0.0048, with three paired seeds and 32,768 updates per run, both controls have higher mean development PPL than GatedV at the matching rate, by 1.77--2.82\% (see Table~\ref{tab:moment} and Section~\ref{sec:activation_LR}). Thus these fixed moment adjustments do not reproduce GatedV's full gain.

\subsection{Evaluation and uncertainty}
For seed $s$, document loss sums $\ell_{s,i}$, and target counts $n_i$, we report token-averaged negative log-likelihood and perplexity as
\begin{equation}
 L_s=\frac{\sum_i\ell_{s,i}}{\sum_i n_i},\qquad P_s=\exp(L_s),\qquad
 \Delta_P=100\left(\frac{\overline P_{\mathrm{GatedV}}}{\overline P_{\mathrm{base}}}-1\right).
 \label{eq:pplchange}
\end{equation}
$\overline P$ is the arithmetic mean of per-seed perplexities, not the exponential of mean NLL. Negative $\Delta_P$ denotes improvement. For multi-seed PPL results, $\pm$ denotes the sample standard deviation across training seeds.

To estimate uncertainty from evaluation texts in the main held-out comparisons~\citep{benchvariance,statsguide}, we keep the trained models fixed and average each document's summed loss difference across seed pairs. We then draw 2,000 bootstrap samples of the documents, with replacement and at the original sample size. For each sample, we recompute the token-averaged NLL difference; the 2.5th and 97.5th percentiles of these estimates define the 95\% bootstrap interval (see Section~\ref{sec:heldout}).

\subsection{Computational cost}
We benchmark the six medium-model checkpoints from the 0.0006 confirmation on NVIDIA DGX Spark with fixed synthetic inputs, batch size 8, and context length 256. We compute paired time ratios from median call times, take the median across rounds for each seed, and average across seeds.

Measured latency increases by 0.70\% for full-context forward passes and 1.14\% for training steps with GatedV (Table~\ref{tab:cost}). Across the 21 paired comparisons, the relative change in forward latency for GatedV versus baseline ranges from $-1.15\%$ to $+2.57\%$. Median peak CUDA allocated memory rises from 1.7525 to 1.8569 GiB \textbf{(5.96\%)}.

\section{Discussion}
\label{sec:analysis}
\label{sec:discussion}
GatedV improves held-out language modeling in both tested configurations without adding parameters. In the medium model, its advantage narrows from 3.66\% at peak LR 0.0006 to 2.40\% at the development-selected rate of 0.0003: lowering the rate improves the baseline more, while GatedV remains better in all three pairs (Appendix~\ref{sec:original_medium}). The branch comparisons show that this benefit is not shared by every activation placement.

\subsection{Comparison with GLU and tanh}
\label{sec:gate_comparison}
GatedV uses a single value projection with sigmoid self-gating. We compare it with two-projection GLU value gates and a parameter-free tanh alternative in the medium model (Table~\ref{tab:value_gates}). The GLU controls use $(UW_C)\odot\silu(UW_G)$ before aggregation, following GLU Attention~\citep{gluattention}. The full-width control retains 384 value dimensions, adding a separate projection; the reduced-width control uses 258 dimensions, the nearest six-head-compatible total width to $2d/3$, to approximate the baseline parameter count. The tanh control applies $V\odot\tanh(V)$ at the original width. All runs process the same sampled training windows and share identical initial weights for corresponding matrices with matching shapes.

\subsection{Limitations}
\label{sec:limitations}
Our experiments are limited to models below 28M parameters on FineWeb-Edu, using 256-token contexts and next-token prediction. Larger models, longer contexts, other corpora, and downstream tasks remain untested. The GLU and tanh comparisons use a single seed, and cost measurements cover only our FP32 implementation.

\section{Conclusion}
\label{sec:conclusion}
Applying SiLU to values before aggregation improves held-out perplexity by 2.03\% and 2.40\% in the two tested Transformer configurations, with all paired confirmation runs improving. The change preserves parameter count, depth, and width. The exploratory controls show that the gain is not shared by every activation placement or learning rate, and that the tested initial-moment adjustments do not reproduce it fully. The measured runtime increase is small in this implementation, but its precise magnitude and the extension to larger models, other tasks, and optimized inference remain unresolved.
